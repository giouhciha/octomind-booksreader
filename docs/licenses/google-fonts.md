# Fuentes incluidas

Octomind Books Reader distribuye las siguientes familias procedentes del repositorio oficial de Google Fonts:

- Lora: `ofl/lora/Lora[wght].ttf`
- Roboto: `ofl/roboto/Roboto[wdth,wght].ttf`
- Roboto Mono: `ofl/robotomono/RobotoMono[wght].ttf`

Las tres se distribuyen bajo la SIL Open Font License 1.1. Una copia de la licencia se incluye en `app/src/main/assets/licenses/google_fonts_ofl.txt`.
